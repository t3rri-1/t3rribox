Upload a file

Upload API

Upload files from your own code and get the same short links as the website. No account or key is needed. Every response is JSON, and CORS is open, so it works from browsers too.

Upload a file

POST{{SITE_URL}}/api/upload

Send the file in any one of the three ways below. The extension of the filename becomes the extension of the link.

Multipart form

Use the field name file.

curl -F "file=@photo.jpg" {{SITE_URL}}/api/upload

Raw bytes

Put the bytes in the body and name the file with the X-Filename header or a ?filename= parameter. With no name, the extension is guessed from Content-Type.

curl --data-binary @photo.jpg \
  -H "Content-Type: image/jpeg" \
  -H "X-Filename: photo.jpg" \
  {{SITE_URL}}/api/upload

JSON with base64

Base64 makes the body a third bigger, so keep these files under about 3 MB.

curl -X POST {{SITE_URL}}/api/upload \
  -H "Content-Type: application/json" \
  -d '{"filename":"photo.jpg","base64":"/9j/4AAQSkZJRg..."}'

Response

{
  "ok": true,
  "url": "{{SITE_URL}}/839201.jpg",
  "id": "839201",
  "name": "839201.jpg",
  "ext": "jpg",
  "type": "image/jpeg",
  "size": 48213,
  "sha256": "9f86d081884c7d65...",
  "duplicate": false
}

The status is 201 for a new file. If the same file was uploaded before, the status is 200, duplicate is true, and you get the existing link.

Files over {{SINGLE_MB}} MB

Vercel rejects any request body over 4.5 MB, so bigger files go up in parts of at most {{SINGLE_MB}} MB. The website does this for you. From code:

  1. Send each part as the raw body of POST /api/upload?chunk=1. Each response has a blob ID.
  2. Send POST /api/upload?complete=1 with JSON holding the filename and the blobs in order (up to {{MAX_CHUNKS}} parts). The response is the same as a normal upload.
const API = '{{SITE_URL}}/api/upload';
const PART = 4_000_000;
const blobs = [];

for (let i = 0; i < buffer.length; i += PART) {
  const res = await fetch(`${API}?chunk=1`, {
    method: 'POST',
    body: buffer.subarray(i, i + PART),
  });
  blobs.push((await res.json()).blob);
}

const done = await fetch(`${API}?complete=1`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ filename: 'clip.mp4', blobs }),
});
console.log((await done.json()).url);

Look up a file

GET{{SITE_URL}}/api/info?id=839201

You can also pass name=839201.jpg, or sha256=… to check whether a file is already hosted before you upload it. The response has the same fields as an upload, with size in bytes.

Errors

A failed request returns a non-2xx status and this body:

{ "ok": false, "code": "too_large", "error": "That file is too large. The limit is {{MAX_MB}} MB." }
codestatusmeaning
blocked_type400The extension is on the block list.
empty_file400The file has no bytes.
no_file400No file was found in the request.
too_large413Over the {{MAX_MB}} MB limit.
rate_limited429GitHub is throttling uploads. The Retry-After header says how many seconds to wait.
storage_*502The storage behind the site had a problem. Try again shortly.

Limits

  • Files can be up to {{MAX_MB}} MB.
  • These extensions are blocked: {{BLOCKED_LIST}}.
  • Uploading the same bytes twice returns the same link.
  • Links are unlisted, not private. Anyone who has a link can open the file.

More examples

Node.js 18 or newer

const form = new FormData();
form.append('file', new Blob([buffer], { type: 'image/jpeg' }), 'photo.jpg');

const res = await fetch('{{SITE_URL}}/api/upload', { method: 'POST', body: form });
const data = await res.json();
if (!data.ok) throw new Error(data.error);
console.log(data.url);

A bot that already has the media in a buffer

const res = await fetch('{{SITE_URL}}/api/upload', {
  method: 'POST',
  headers: { 'Content-Type': mimetype, 'X-Filename': `media.${ext}` },
  body: buffer,
});
const { url } = await res.json();

Python

import requests

r = requests.post("{{SITE_URL}}/api/upload", files={"file": open("photo.jpg", "rb")})
print(r.json()["url"])
